# Dependencies and branding

Dependencies are fetched by the build tools rather than committed as source copies:

- ESP32 Arduino framework through PlatformIO `espressif32@6.10.0`.
- NimBLE-Arduino `1.4.3` by h2zero.
- Android Gradle Plugin `8.13.2`, Gradle Wrapper `8.13`.
- Tests: JUnit `4.13.2` and Robolectric `4.14.1`.

Each dependency retains its own license. The Gradle Wrapper is part of the Gradle project and is distributed under Apache-2.0.

The PedalBridge symbol was generated for this project using OpenAI Imagegen and adapted to Android icon sizes. Garmin and Bodytone trademarks belong to their respective owners. The project name does not imply trademark clearance.
